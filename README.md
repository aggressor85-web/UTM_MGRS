# iPhone向け UTM・MGRS 座標計算 PWA

## GitHub Pages への公開手順（Windowsでも可能）

1. GitHubで新しい**Public**リポジトリを作成します（例: `utm-mgrs-pwa`）。
2. このZIPを展開し、`index.html`、`manifest.webmanifest`、`sw.js`、PNGファイルをすべて**リポジトリの最上位**にアップロードしてコミットします。ZIPファイル自体はアップロードしません。
3. GitHubのリポジトリ画面から **Settings → Pages** を開きます。
4. **Build and deployment → Source: Deploy from a branch** を選び、**Branch: main / (root)** を選択して保存します。
5. 数分待ち、Pagesに表示される公開URLを開きます（例: `https://ユーザー名.github.io/utm-mgrs-pwa/`）。
6. iPhoneの**Safari**でそのURLを開き、共有ボタン → **ホーム画面に追加** → 追加。
7. ホーム画面のアイコンから起動。初回オンライン起動後に、機内モードで再起動してオフライン動作を確認してください。

## 注意点
- GitHub Pagesの通常の公開サイトは誰でも閲覧できます。機密の位置情報をファイルに書き込まないでください。
- 座標計算は端末内で実行され、入力値をサーバーに送信するコードはありません。
- 6400ミルは円周を6400等分した単位です。方位角はUTM格子北基準です。
- 平面座標上の簡易計算です。縮尺補正、ゾーン境界を越えた再投影、弾道計算はありません。
- キャッシュ初回保存にはHTTPSでのアクセスが必要です。ファイルをiPhoneにコピーして開くだけではPWAとしてのインストールとオフラインキャッシュは完成しません。
- サービスワーカーの更新後は、オンラインで再起動して新しい版がキャッシュされたことを確認してください。
